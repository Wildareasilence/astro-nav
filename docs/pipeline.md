# 全天照片盲定位：可复现流程说明

从一批未知指向的广角星场照片 + 三维星表，反解观察者位置。
本文记录每一步的输入、输出、判据、以及踩过的坑，供日后重跑或复核。

---

> **定位器**：`src/locator/`（并入的 stellar_locator）是另一条已验证的完整链路，
> 统一网格拍摄 + 一条命令出位置，实测 303 AU @ 67.23 ly。见 README「定位器」一节。
> 本文描述的是逐步链路（01–05 脚本）。

## 1. 星点提取

**代码** `photometry.py` → `prep2.detect_all()`

**输入** PNG。**输出** `frames*.npz`，每帧 `(x, y, mag)`。

做法：32 px 块中值背景 → 局部 3×3 极大 → 5×5 通量质心。
再用 **3×3/5×5 紧凑度 > 0.62** 过滤，去掉星云结构。

**判据**：紧凑度筛掉后仍保留 1 万以上点源。

> 注意：`mag = -2.5·log10(flux)`，值越负越亮。不要用别的列排序。

---

## 2. 帧间配对（旋转不变）

**代码** `pairmatch.try_match()`

**输入** 每帧最亮 40 颗的相机方向。**输出** `(共同星数, R, 残差)`，
满足 `cam_a @ R = cam_b`（即 `R = M_a^T M_b`）。

做法：所有三角形按三边长排序，在边长空间做容差匹配，Kabsch 拟合，内点重拟合。

**判据**：共同星 ≥ 6 且中位残差 ≤ 1 角分。
实测 A 组 81 对（0.34–0.91′），B 组 64 对（0.29–0.76′）。

---

## 3. 拼接

**代码** `rebuild.propagate()`

```
R[b] = R[a] @ Rab        ← 只有这一种写法
```

**输入** 配对边。**输出** 每帧相对种子帧的旋转。

**判据**：三帧闭合检验。A 组 135 组环路，中位偏差 **0.013°**，最大 0.04°。

> **坑 1**：这里曾经写成 `R[b] = Rab.T @ R[a]`。后果是只有种子帧正确、其余全歪，
> 表现为"环不闭合、银极错位、接不上星表"。用合成数据判定：正确写法姿态误差 0.05°，
> 错误写法 114.7°。

## 4. 绝对定向

拼接只给出相对姿态，差一个全局旋转。

### 4.0 完全盲解（默认路径）

不需要任何指向信息。**代码** `src/starlock.py`

```
1. 该帧最亮的 80 颗，两两 >0.8°（避开双星、混合像元）
2. 取最亮 6 颗的若干对，用它们的角距去星表亮星（G<7，前 400 颗）里找同长配对
      tol = 120″，一对角距在星表里通常只有几个同长者
3. 每个配对 → 一个旋转（align 两矢量 + 绕第一颗的方位修正）→ 投影全部星表
      星表 G<9 ≈ 11 万颗，视场内约 1–2 千，命中数随机期望个位数
4. 最优解 Kabsch 精修（残差从几角分压到几十角秒），交 calibrate_frame
```

**前提**：两边的「最亮 80 颗」必须是同一批天体。实测确认：观测亮度排名与星表 G
单调对应（G 2–5 的星正是检出最亮的前 200 颗），所以这个前提成立。

**实测**（A 组 9 帧，覆盖银道圈 / 上下两圈 / 两银极）：误差 3–14″，中位 9″，
每帧 16–27 s。整组 27 帧 → 与真值差 2″，位置 112.7 AU，与精确 RA/Dec 锚点一致。

**位移的硬限制**（这一条最重要）。星图识别假设「拍到的图案 ≈ 星表图案」。
位移 `x` 让距离 `L` 的星挪 `x/L`，而可用亮星的中位距离只有几百 pc：

| 离太阳 | 匹配策略 | 实测误差 |
|---:|---|---:|
| 0 | 全星表，120″ | 4″ |
| 1 ly | d>200 pc，300″ | 58–67″ |
| 3 ly | d>300 pc，600″ | 129″ |
| 10 ly | d>500 pc，1500″ | 425″ |
| 30 ly | d>800 pc，2400″ | 841″ |
| 100 ly | — | 错解 |

规律：容差必须 ≥ `|x|/L_min`，而 `L_min` 越大可用星越少、判别力越弱。两头夹逼，
到 ~100 ly 就没有可用组合了。这不是打分函数的问题，是图案真实变了。

### 4.1 粗锚点

**不需要赤经赤纬。** 现场只需要一句「哪一帧大致对着哪个天体」——银心、银极、大小麦云、
M31，这些是天空里客观存在的方向，认得出就能用，误差 ±15° 都行。

三种方式，按数据集情况选（`datasets.py` 的 `anchor` 字段）：

| 情况 | 做法 | 代码 |
|---|---|---|
| 认得出天体（推荐） | 以该方向为光轴建粗姿态 → 互相关粗定 | `register.coarse_lock()` |
| 有精确赤经赤纬 | `frame_M_radec(ra,dec)` → 扫滚转 | `attitude.solve_roll()` |
| 有与已标定组的重叠帧 | 直接继承 `M_new = M_old @ Rᵀ` | `03_attitude.py` 的 link 分支 |

**为什么必须两步。** 像素级点匹配的有效半径只有几个像素（165″/px ⇒ 6 px ≈ 0.28°）。
要在 ±15° 上做 3 自由度网格，步长得 ≤0.15°，那是 200 万次评估，做不到。
而图像互相关对平移不敏感：一次 FFT 就能把 0–15° 的平移解出来，剩下的滚转用 120 次扫描。

```
1. 滚转 θ 全扫（3° 步长, 4× 降采样图）：
     渲染星表亮星 → rfft2 → 与实拍星点图互相关 → 取峰值高度最大的 θ
2. 峰值位置 (dx,dy) 换算成姿态小旋转：
     ω = (dy/FOC, −dx/FOC, 0)          （中心处精确）
3. 原分辨率再来一遍（滚转 ±4°、0.25° 步长）→ 残差 0.05–0.1°
4. 交 calibrate_all，从 15 px 半径接管
```

实测捕获能力（A 组 r0_00，起手故意打偏）：

| 扰动 | 起手误差 | 互相关后 |
|---|---:|---:|
| 纯平移 100 px | 5.4° | 0.10° |
| 纯平移 −200 px | 10.1° | 0.05° |
| 倾斜 +5°/−4°、滚转 +20° | 14.4° | 0.08° |
| 倾斜 +8°/−6°、滚转 +25° | 16.7° | 0.05° |
| 倾斜 +10°/0、滚转 +30° | 26.9° | 失败 |
| 滚转 ±90°/150°/−120° | 92–153° | 0.09° |

滚转不设限（0–360° 全扫，约 9 秒）；限制来自指向误差——超过 ~20° 目标星场就大片跑出画幅。

> **坑 3**："银道水平"不等于滚转 0。实测偏 **0.674°**，在 2560 px 上等于 14.6 px，
> 足以让所有像素级匹配全部失效。所以滚转必须扫，不能假设。

### 4.2 逐帧对星表精修

**代码** `posefit.calib_frame_scale()`

参数：相机系三轴小旋转 + 径向尺度。数值雅可比，Gauss-Newton，半径从 15 px 收到 0.4 px。

**判据**：内点 1000+，中位残差 ≤ 0.2 px。

| 组 | 帧数 | 内点 | 中位残差 | 修正转角 |
|---|---:|---|---:|---:|
| A | 27/27 | 1083–1507 | 0.149–0.181 px | 0.16–0.18° |
| B | 15/15 | 1111–1338 | 0.149–0.175 px | 0.00–0.01° |

> B 组是从 A 组继承姿态的（通过银道圈帧对接），所以修正量约为 0。

## 5. 位置解算

**代码** `model_cmp.py`

模型（同时含位置与光行差）：

```
w_pred = normalize( unit(p_i − x) + (I − w wᵀ)·v/c )
```

- `p_i` 是第 i 颗星的三维位置（AU）
- `x` 是待求的观察者位置（AU）
- `v` 是待求的"光行差速度"（km/s）

两个偶极项的形状相同，只差权重：位置项 ∝ 1/d，光行差项 ∝ 常数。
距离跨度 10–180 pc（18 倍）足以分开。

**判据**：χ²/N 比较三个模型。

| 模型 | A 组 27 帧 | B 组 15 帧 |
|---|---|---|
| 只有位置 x | 0.2156（\|x\|=603 AU） | 0.2290（\|x\|=638 AU） |
| 只有光行差 v | **0.2015　v=19.6 km/s** | **0.2139　v=20.8 km/s** |
| 两者 | 0.2012（\|x\|=**103 AU**） | 0.2136（\|x\|=**110 AU**） |

> **坑 4**：只解位置时得到 600 AU，方向 l≈240°, b≈−23°——
> 正好是**反太阳向点**。那不是位置，是速度。光行差模型拟合更好，
> 且反演出的速度 19.6/20.8 km/s 与太阳本动 19.5 km/s（l=57°, b=+22°）吻合。

## 6. 结果

```
x = (−3, +88, −67) AU     |x| = 110 AU
真值 ≤ 0.07 AU（10⁷ km）   → 与地球一致
换算 |x| = 5×10⁻⁴ pc = 0.002 光年
```

附带独立测量：

```
测得  19.6 ± 0.6 km/s   指向 l = 59.0°, b = +24.5°
已知  19.5 km/s         指向 l = 57°,  b = +22°
```

整条链路反演出太阳在银河系中的本动，速度差 0.5%，方向差 3–5°。

## 7. 精度账

| 阶段 | 位置精度 | 原因 |
|---|---:|---|
| 只解位置 | 600 AU | 14.3″ 光行差偶极被当成视差 |
| **扣光行差（当前）** | **103–110 AU** | 残余为单星质心误差 |
| 45° 视场（外推） | ~79 AU | 像素尺度 119″/px，×0.72 |
| 30° 视场（外推） | ~51 AU | 77″/px，×0.46 |
| 改质心算法 | **无效** | 已到渲染器极限 |

单星质心误差的实测依据：

- PSF 采样良好：峰值像素占 5×5 的 13%，3×3 占 77%（σ≈1 px，**不欠采样**）
- 同星两帧重复性（r0_00/r0_01，共同 4625 颗）：质心差中位 0.28 px，RMS 0.38 px
  ⇒ 单星误差 ≈ 0.2 px = **33 角秒**
- 高斯权重质心（环形背景 + σ=1.2 px）实测**更差**：0.198 px vs 原 0.165 px

> 理论上亮星（数千光子、σ≈1 px）的质心精度应是 0.02 px。实测 0.2 px，差一个量级，
> 且换算法不改善 ⇒ 限制来自渲染器的亚像素精度，不是提取算法。

## 8. 三个诊断方法（复用价值最高）

### 8.1 距离分层

同一个拟合，改变星表距离上限。若是真视差，答案不随上限变；若是"恒定角度 × 距离"的系统差，则 |x| 随上限增长。

```
d<40pc → 299 AU，d<70 → 406，d<120 → 524，d<200 → 603
```

→ 增长 ⇒ 有系统差。

### 8.2 同天区不同滚转

同一片天、两张相差 90° 滚转的照片。残差图案若在**探测器坐标**下一致 ⇒ 探测器问题；若转 90° ⇒ 天球/星表问题。

实测：poleU_0/poleU_1 逐块残差向量夹角中位 **9°**，poleD 对 **16°**。
（当时的解读是"探测器固定"，但后续 128° 滚转的新组给出同样位置，推翻了这一解读——
最终定位到光行差，属于天球效应。**教训：滚转对比只在该对确实覆盖同一片天且残差量级大于噪声时有效。**）

### 8.3 三模型 χ² 比较

位置（∝1/d）vs 光行差（∝常数）vs 两者。这是区分两个同形状偶极的唯一手段。

## 11. 若要进一步提高精度

1. **窄视场**：45° → 79 AU，30° → 51 AU。这是唯一有效杠杆。
2. **更多帧**：σx ∝ 1/√N。
3. **更细的传感器**：像素尺度线性改善。
4. 改质心、改匹配半径、加畸变项：已测，均无实质收益。

## 12. 未解决 / 待验证

- 渲染器为什么带 19.6 km/s 的光行差（是否为 SE 自身模型），未与 SE 文档核对。
- 45° 视场的外推精度尚未实测（需要重拍一组）。
- 剩余 ~100 AU 中质心误差与星表误差的占比未分离。
- **完全盲解在 |x| ≳ 1 ly 时失效，且这不是能靠改算法补上的。**
  已验证：0 ly 时 4″，1 ly 时 ~60″，3 ly 时 129″，10 ly 时 0.12°，30 ly 时 0.23°，100 ly 错解。
  原因见 §4.0 的表。`starlock.blind_auto` 想自动挑「用多远的星」，但只在 1 ly 内可靠。
- **正确的下一步是 6 自由度联合搜索（未实现）。** 用候选位置 x 预测星空，再跑盲解；
  真值附近紧容差命中数会从 ~24 跳到 ~154（已实测这个判据在 x=0 处很锐）。
  代价：100 ly 球内 20 ly 网格约 520 个候选 × 每帧约 25 s ≈ 4 小时/帧，且需要先解决
  「每个候选位置都要重跑一次滚转扫描」的成本。可行但没有实施。
- 用天球密度直接拟合银极（不依赖星点识别）只能到 4–12°，且二维密度相关有
  l→l+180°/b→−b 的二重简并，因为银河近似有这条对称性。
- **D 组（新位置，41 帧）验证结果**：几何全通（41/41 连通、108 对重叠、残差 0.2–1.0′），
  焦距经独立扫描确认 1247 px。姿态的前 2 个自由度由拍摄布局自定标出来——
  银道带 18 个光轴拟合平面的法向与四张极片光轴相差 **0.8°**，两银极夹角 **179.0°**，
  b_00 光轴与极轴夹角 91.1°（与「b_00 对着银心」自洽）。
  但第 3 个自由度（方位角）解不出来：即使把「b_00≈银心」和银极都用上（两个方向唯一确定姿态），
  星点匹配也只有 10/150 @400″（随机 0.5），逐帧精修 0/41。
  结论：该位置天球图案与星表在 0.1° 量级上不一致，与位移实验的规律一致。
  顺带修掉一个目录缺陷：全天亮星表原本缺 RA 90–120° 和 270–300° 两片（各 30°），
  已补全（现 87,434 颗，距离中位 290 pc）。
